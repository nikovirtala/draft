# Let the room name its agent

## Goal
The room calls its agent by a name everyone sees, chosen so that the models hear it reliably in Finnish and English.

## Notes
- The name is a context setting, "draft" until someone changes it; a rename is an event (relates to ?45, settings).
- Choosing one plays it back: draft records the name said a few times and shows how the models hear it in each language (canvas Voice, marker 11), so a name that transcribes badly is caught before the mob starts.
- Matching runs on the transcript and tolerates near misses; whether that is reliable enough is measured separately.

## Done when
- A rename is logged and shown to everyone in the room.
- The playback check shows how each language heard the name before it is saved.
