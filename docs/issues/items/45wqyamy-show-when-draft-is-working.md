# Show when draft is working

## Goal
The person can always see that draft is doing something, and what.

## Notes
- Niko's feedback after using draft on 23 Nov 2026. Today reading from GitHub shows only a line of text at the map's foot, and an agent turn, a stub resolving or a context opening show nothing.
- One indicator with one look everywhere (consistency): where the work shows (the block, the stub, the map), plus one quiet place for work with no block of its own, such as the footer. It names what is going on in words for screen readers, and appears only after a short delay so quick work doesn't flicker.

## Done when
- An agent turn, a stub resolving, the map reading GitHub and a context opening each show the indicator, and only while working; tests cover the delay.
