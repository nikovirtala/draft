# Accept an ADR that is already on the default branch

## Goal
Offer acceptance for a proposed ADR that landed on the default branch without being accepted.

## Notes
Acceptance needs the proposing pull request's branch for the accept commit, so an ADR proposed on main gets no request today (ADR ytmnx1br). It needs a branch and a pull request made as the person.

## Done when
- A proposed ADR on the default branch with green verify gets an acceptance request.
- Accepting makes a signed accept commit on a new branch and opens a pull request as the person.
