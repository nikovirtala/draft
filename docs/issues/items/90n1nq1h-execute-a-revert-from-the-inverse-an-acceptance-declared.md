# Execute a revert from the inverse an acceptance declared

## Goal
Plan and run the compensation recorded with an accepted ADR or a merge.

## Notes
Every acceptance records its inverse (supersede or withdraw an ADR, a revert commit through a pull request, reopen a closed pull request). Nothing runs it. docs/model.md, Revert.

## Done when
- A revert of an acceptance is previewed and runs as a durable saga of the person's steps.
