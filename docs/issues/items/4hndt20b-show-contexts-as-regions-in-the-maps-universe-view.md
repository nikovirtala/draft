# Show contexts as regions in the map's universe view

## Goal
The map's zoom levels include the universe: contexts as regions with their boundaries, built from the registry's names, folders and last activity.

## Notes
The registry already lists contexts with those fields. References across contexts (context.crossed) give the edges.

## Done when
- The universe zoom lists every context with its name, folder and last activity.
- Crossings are drawn between regions.
