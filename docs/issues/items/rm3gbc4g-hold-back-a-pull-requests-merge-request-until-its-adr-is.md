# Hold back a pull request's merge request until its ADR is accepted

## Goal
Do not offer the merge of a pull request that proposes an ADR that is still proposed.

## Notes
Both requests show together today. Merging first lands the ADR as proposed, and then it has no pull request to accept on. The pull request resolver does not list files yet.

## Done when
- A pull request that carries a proposed ADR gets no merge request until the ADR is accepted on its branch.
