# Let the agent suggest opening or making a context

## Goal
The agent can propose a context for something it found, shown as the same one-action confirmation as a sentence.

## Notes
Out of scope of the first contexts slice: only a person's sentence makes a proposal. Suggestions must stay proposals; the agent never opens one. Relates to the focus proposal in 039smma8.

## Done when
- An agent suggestion appears as a proposal and opens nothing until confirmed.
- The suggestion is recorded as the agent's.
