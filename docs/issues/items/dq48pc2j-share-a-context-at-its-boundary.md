# Share a context at its boundary

## Goal
A context can be shared with other people, who place it on their own devices; the folder binding stays per device.

## Notes
The log already records the trust decision by remote and path hash, never a path. Open: how a shared log names the same context for people who have different registry names, which also covers imported logs whose addresses say local.

## Done when
- Another person opens the same context and is asked about their own folder.
- Names in addresses are the same for everyone.
