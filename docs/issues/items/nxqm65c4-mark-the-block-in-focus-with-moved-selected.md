# Mark the block in focus with moved-selected

## Goal
The block in focus, and the row you are on, take moved-selected with ink words, as the design system's Selection preview shows.

## Notes
A selected stub keeps a moved-mark hairline today, because muted words (the stub's status and reference) fall under 4.5:1 on moved-selected. The words inside a selected block need a pair that reaches 4.5:1 there first.

## Done when
A selected or focused block is drawn on moved-selected, every text colour in it reaches 4.5:1 on it, and the contrast test lists the pairs.
