# PromptAndInterrupt

A block that asks the person for something is the one block that takes a fill: `waiting-fill`, a `line-strong` hairline, never red and never purple. It has a label in `waiting-word` with its age, a body in `ink`, the draft's record in a `surface` box where there is one, and the person's buttons (one main action at most). Settled, it drops the fill and is one line of history.

The preview draws an interrupt (a call without asking), a failed check's interrupt beside the pull request stub that carries the failure chip, an interrupt for a wait that ended, a permission prompt (Allow is the main action) and a failure notice (the failure chip at block size, a cross and its words). Keyboard focus is on "I've seen it": a 1.5px `moved-mark` ring, no fill.

Screenshots it is compared with: `07`, `c01`, `fw05`.
