# Evidence

An acceptance request asks the person for something, so it is `waiting-fill` as a whole, with a label and its age. Under it is the evidence, one row per check: a state chip, the check's name in `ink`, and its detail in `muted`. The words Passed, Failed and Waiting are always written; they are not hidden from screen readers. It ends with what accepting does and three answers: Accept as the main action, Request changes and Reject. Keyboard focus in the preview is on Accept: a 1.5px `moved-mark` ring, no fill.
