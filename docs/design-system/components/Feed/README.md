# Feed

What Kiro Remote's change feed says, in the places draft shows it. A session that waits for a pull request has a `waiting-mark` edge at the weight of a cascade, with an arrow to it, and a wait chip in its stub ("Waiting for owner/repo#7"). When the wait ends, the edge goes and a moved chip says why it woke. When the feed stops at something draft cannot read, a note says so, a wait chip marks the waits as possibly out of date, and the provenance line says where it stopped. The legend names every mark in words.

Keyboard focus in the preview is on the waiting session's stub: a 1.5px `moved-mark` ring, no fill.
