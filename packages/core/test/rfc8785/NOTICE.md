# RFC 8785 test data

`input/` and `output/` are the JSON Canonicalization Scheme test files from
[cyberphone/json-canonicalization](https://github.com/cyberphone/json-canonicalization/tree/master/testdata)
(the reference implementation by RFC 8785's author), Copyright 2018 Anders Rundgren, under the
Apache License 2.0. They are kept byte for byte: Biome is told not to format this directory.
